## In plain terms

The text above is the license, which must accompany any reproduction. What it
means, without the legalese:

- **The score measures what the rubric measures, in the configuration it was run
  in.** Change the model that simulates the patient, the judge, the number of
  turns, or the rubric version, and the number changes. Comparing scores only
  makes sense across runs with the same configuration.
- **Nobody certified anything.** Spring Care maintains the benchmark. It did not
  evaluate Nami, did not review this repository, and does not endorse the result.
- **This is not a clinical decision.** Not for someone building a chatbot, and
  not for someone choosing one. It is a measurement, published so it can be
  checked.

## Crisis resources

This repository contains transcripts of simulated conversations about suicide.
The personas are synthetic — no real patient appears here. If you need help now:

- **United States** — 988 Suicide & Crisis Lifeline: call or text **988**.
- **Brazil** — CVV, emotional support and suicide prevention: **188** (24/7, free)
  or [cvv.org.br](https://www.cvv.org.br).
- **Elsewhere** — [findahelpline.com](https://findahelpline.com) lists crisis
  lines by country.
